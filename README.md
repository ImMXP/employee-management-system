## 💡 نظرة عامة

هذا المشروع يمثل **نظاماً مبسطاً لإدارة الموظفين** تم تطويره باستخدام لغة البرمجة **Java** مع التركيز القوي على تطبيق مفاهيم **البرمجة الشيئية (OOP)**.

الهدف الأساسي هو توضيح كيفية تصميم نظام يتسم بالمرونة وقابلية التوسع من خلال: **التغليف (Encapsulation)**، **الوراثة (Inheritance)**، و **تعدد الأشكال (Polymorphism)**.

## 🚀 الميزات الرئيسية

* **تصنيف الموظفين:** يدعم النظام تصنيف الموظفين إلى فئات مختلفة (مثل `Engineer`، `Intern`، `Manager`) باستخدام الوراثة من فئة أساسية هي `Employee`.
* **هيكل بيانات واضح:** تنظيم بيانات الموظفين بشكل منطقي داخل الكلاسات.
* **قابلية التوسع:** سهولة إضافة أنواع جديدة من الموظفين أو سمات (Attributes) لهم دون التأثير على الهيكل الأساسي.
* **منفذ اختبار:** يتضمن الملف `TestEmployee.java` لضمان عمل كافة الكلاسات والوظائف بشكل صحيح.

## ⚙️ البدء والتشغيل

لتشغيل كود Java هذا محلياً، تحتاج إلى بيئة تطوير Java (JDK).

### المتطلبات الأساسية (Prerequisites)

* **Java Development Kit (JDK):** الإصدار 8 أو أعلى.
* **بيئة تطوير متكاملة (IDE):** مثل IntelliJ IDEA, Eclipse, أو VS Code مع حزمة دعم Java.

### خطوات التشغيل

1.  **استنساخ المستودع (Clone the repository):**
    ```bash
    git clone [https://github.com/ImMXP/OOP-Based-Employee-Management-System.git](https://github.com/ImMXP/OOP-Based-Employee-Management-System.git)
    ```
2.  **فتح المشروع:**
    * افتح مجلد المشروع في IDE الذي تختاره.
3.  **تجميع وتشغيل الملف:**
    * قم بتشغيل الملف `TestEmployee.java` الذي يحتوي على الدالة الرئيسية (`main method`).
